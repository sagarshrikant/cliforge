# calctool Command-line Reference

Plugin-capable expression evaluator

calctool evaluates mathematical expressions from the command line. It supports a plugin system for user-supplied operator packs loaded as shared objects at runtime. 

**Version:** 0.2.0  **Author:** Your Name

## Options

### General

Core evaluation settings. Apply globally across all subcommands unless a subcommand overrides them locally. 

#### `--precision`

Decimal precision used internally by the evaluator.

Values above 24 are rarely needed for general use.

**Example:** `calctool --precision 24 eval '1/3'`

*Since 0.1.0*

#### `--mode`

Top-level evaluation mode (integer, real, or complex).

**Example:** `calctool --mode integer eval '7 / 2'`

#### `--verbosity`

Verbosity level.

#### `--logfile`

Log file path.

#### `--work-dir`

Working directory for relative-path expressions.

#### `--config-file`

Optional TOML configuration file path.

#### `--no-prompt`

Suppress the interactive prompt in REPL mode.

#### `--locale`

Override LC_NUMERIC locale for decimal formatting.

#### `--nice`

Unix nice(2) value for the evaluator process.

#### `--rpc-port`

TCP port for the JSON-RPC interface.

#### `--seed`

PRNG seed. -1 = auto-seed from /dev/urandom.

#### `--byte-offset`

Internal file byte offset (test hook).

#### `--max-vars`

Maximum number of user-defined variables.

#### `--max-steps`

Maximum evaluation steps before soft timeout.

#### `--feature-flags`

Internal feature-flags bitmask (reserved).

#### `--progress-interval`

Progress-bar update interval in seconds.

#### `--epsilon`

Floating-point equality tolerance for == operator.

#### `--api-token`

API token forwarded to plugins requiring authentication.

*Since 0.2.0*

#### `--api-url`

Remote API endpoint used when --api-token is set.

#### `--old-mode`

(Deprecated) legacy mode string.

### Output

Output format and destination settings.

#### `--format`

Result output format.

#### `--color`

Force ANSI color even when stdout is not a TTY.

#### `--json`

Shorthand for --format json.

#### `--outfile`

Write results to this file instead of stdout.

#### `--encoding`

Output character encoding.

#### `--syslog-tag`

Syslog identifier tag.

### Performance

Resource budgets for the evaluation engine.

#### `--deadline`

Soft timeout per evaluation.

**Example:** `calctool --deadline 500ms eval '1/3'`

#### `--stack`

Per-thread stack size for recursive evaluation.

#### `--memory-budget`

Working-set memory budget (advisory; plugins may consult this).

#### `--sample-rate`

Sampling rate for the profiler integration.

#### `--gc-threshold`

Trigger GC when this fraction of the memory budget is used.

### Plugins

Runtime plugin loading via dlopen. Plugins extend the operator set available to expressions. 

#### `--plugin`

Plugin .so to load at startup. Repeat for each plugin.

path: path to the shared object. name: dispatch key in expressions (e.g. fin(x, y)). priority: lower numbers run first when plugins share an operator. 

**Example:** `--plugin path=./num.so,name=num,priority=20`

#### `--loader`

Plugin loader settings: sandbox enable + load timeout (ms).

#### `--plugin-path`

Colon-separated dirs searched when plugin path has no slash.

#### `--no-sandbox`

Disable plugin sandboxing. CI and power users only.

#### `--plugin-abi`

Plugin ABI version to enforce.

### Threading

Worker thread pool configuration.

#### `--workers`

Number of packet-processing worker threads.

#### `--thread-sched`

Scheduling policy for worker threads.

#### `--thread-prio`

Thread priority (only meaningful for SCHED_RR and SCHED_FIFO).

#### `--cpu-mask`

CPU affinity bitmask (hex). 0x0 = no pinning.

#### `--crypto-key`

AES-256 key for encrypting output (hex string, 64 chars).

#### `--extended-precision`

Enable 80-bit extended-precision mode (x87).

#### `--angle-unit`

Angle unit for trigonometric functions.

#### `--debug-asm`

Dump generated bytecode assembly to stderr.

## Subcommands

### `eval`

Evaluate one or more expressions

Parses and evaluates each expression in order.

- `--echo` — Echo each expression before printing its result.
- `--max-depth` — Maximum evaluator recursion depth.
- `--profile-out` — Write profiling data to this file.

### `bench`

Benchmark a plugin under load

Runs a plugin's primary operator N times.

- `--iterations` — Number of iterations to run.
- `--warmup` — Warmup iterations before timing starts.
- `--report-interval` — How often to print intermediate throughput results.

### `evaluate`

(Deprecated) alias for eval

> **Deprecated:** use 'eval' since 0.1.0


## Imported Library Options

The following options belong to libraries imported with `@import`.  They are passed through by the generated parser unchanged and must be forwarded to each library's own parser by the host application using `cf_argv_slice()`.

```c
#include <cliforge/cf_argv_slice.h>

char  *lib_argv[CF_SLICE_MAX_ARGS];
char   lib_buf[CF_SLICE_STRBUF];
int    lib_argc = cf_argv_slice("<alias>",
                               argc, argv,
                               lib_argv, CF_SLICE_MAX_ARGS,
                               lib_buf,  CF_SLICE_STRBUF);
/* then pass lib_argc / lib_argv to the lib's init() */
```

### `arith` — Basic arithmetic operators (+, -, *, /)

Supply on the command line as `--arith.OPTION=VALUE`.
Forward to the library with `cf_argv_slice("arith", ...)` before calling the library's init function.

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `--arith.div-zero` | ENUM | `error` | Behaviour when evaluating x / 0. |
| `--arith.epsilon` | DOUBLE | `1.0e-9` | Tolerance below which results are clamped to zero. |
| `--arith.rounding` | ENUM | `nearest` | Rounding rule applied at the end of every binary operation. |

### `cmp` — Comparison operators (<, >, ==, !=, <=, >=)

Supply on the command line as `--cmp.OPTION=VALUE`.
Forward to the library with `cf_argv_slice("cmp", ...)` before calling the library's init function.

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `--cmp.epsilon` | DOUBLE | `1.0e-12` | Floating-point comparison tolerance. |
| `--cmp.nan-equal` | BOOL | `false` | Treat NaN as equal to itself for the == operator. |

### `trig` — Trigonometric ops (sin, cos, tan, asin, acos, atan2, ...)

Supply on the command line as `--trig.OPTION=VALUE`.
Forward to the library with `cf_argv_slice("trig", ...)` before calling the library's init function.

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `--trig.units` | ENUM | `radians` | Unit used to interpret arguments to trig functions. |
| `--trig.normalize` | BOOL | `true` | Reduce input angle modulo 2π before evaluation. |
| `--trig.method` | ENUM | `taylor` | Numerical method for high-precision evaluation. |

### `stats` — Statistics ops (mean, stddev, variance, median, ...)

Supply on the command line as `--stats.OPTION=VALUE`.
Forward to the library with `cf_argv_slice("stats", ...)` before calling the library's init function.

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `--stats.mode` | ENUM | `sample` | Use Bessel-corrected (n-1) divisor or plain n for variance/stddev. |
| `--stats.max-points` | UINT32 | `1_000_000` | Maximum number of data points accepted by stats functions. |
| `--stats.epsilon` | DOUBLE | `1.0e-10` | Tolerance for incremental-mean convergence detection. |
