cliforge apt repository

CLI parser-generator for C89/C99/C11 projects.

Install

# 1. Add the signing key
curl -fsSL https://sagarshrikant.github.io/cliforge/cliforge-archive-keyring.gpg | sudo tee /usr/share/keyrings/cliforge-archive-keyring.gpg > /dev/null

# 2. Add the repository
echo "deb [signed-by=/usr/share/keyrings/cliforge-archive-keyring.gpg] https://sagarshrikant.github.io/cliforge stable main" \
  | sudo tee /etc/apt/sources.list.d/cliforge.list

# 3. Install
sudo apt update
sudo apt install cliforge

Updates arrive through normal sudo apt update && sudo apt upgrade.

Source & releases: github.com/shrikant-sagar/cliforge
